# 🐧 سامانه آزمون آنلاین LPIC و Network+

یک پلتفرم جامع، مدرن و ریسپانسیو برای تمرین و آمادگی آزمون‌های **LPIC-1**، **LPIC-2** و **Network+**. این پروژه با استفاده از Flask و جاوااسکریپت خالص (Vanilla JS) ساخته شده و دارای قابلیت‌های هوشمند مانند **آزمون تطبیقی (AI Adaptive)**، **تشخیص خودکار نوع محتوا** و **پنل ساخت آزمون حرفه‌ای** است.

---

## ✨ ویژگی‌های کلیدی

- 🧠 **آزمون هوشمند تطبیقی (AI Mode)**: شروع با ۴ سوال از سطوح مختلف، سپس تنظیم خودکار سطح دشواری سوالات بعدی بر اساس **درستی پاسخ** و **سرعت عمل** کاربر به همراه تایمر زنده.
- 🔍 **تشخیص هیبریدی نوع آزمون**: تشخیص خودکار نوع آزمون (عمومی، دستورات لینوکس، یا شبکه) بر اساس نام فایل، عنوان و محتوای سوالات.
- 🛠️ **پنل ساخت آزمون حرفه‌ای**: 
  - ورود فیلد به فیلد با پیش‌نمایش زنده.
  - چسباندن هوشمند متن از کلیپ‌بورد و تبدیل خودکار به فرمت JSON.
  - تولید خودکار پرامپت مهندسی‌شده برای دریافت سوالات باکیفیت از ChatGPT/Claude/Gemini.
- 📚 **مدیریت پیشرفت کاربر**: ذخیره خودکار پاسخ‌ها، آمار صحیح/غلط، و بوک‌مارک کردن سوالات در `LocalStorage` مرورگر.
- 🎨 **رابط کاربری مدرن**: طراحی Dark Mode زیبا، انیمیشن‌های روان، کاملاً ریسپانسیو (سازگار با موبایل و دسکتاپ) و پشتیبانی کامل از زبان فارسی (فونت وزیرمتن).
- ⚡ **سبک و سریع**: بدون نیاز به فریم‌ورک‌های سنگین فرانت‌اند، اجرا شده با Vanilla JS و Flask.

---

## 🛠️ پشته فناوری (Tech Stack)

- **Backend**: Python, Flask
- **Frontend**: HTML5, CSS3 (Custom Variables, Flexbox/Grid), Vanilla JavaScript
- **Fonts**: Vazirmatn (فارسی), JetBrains Mono (کد و اعداد)
- **Storage**: LocalStorage (برای ذخیره پیشرفت کاربر در سمت کلاینت)

## 🚀 نصب و راه‌اندازی

### ۱. کلون کردن پروژه
```bash
git clone https://github.com/your-username/lpic-quiz-server.git
cd lpic-quiz-server
```

### ۲. نصب وابستگی‌ها
مطمئن شوید Python 3.8+ نصب است. سپس Flask را نصب کنید:
```bash
pip install flask
```
*(یا اگر فایل `requirements.txt` دارید: `pip install -r requirements.txt`)*

### ۳. اجرای سرور
```bash
python server.py
```

### ۴. دسترسی به برنامه
مرورگر خود را باز کنید و به آدرس زیر بروید:
👉 [http://127.0.0.1:5000](http://127.0.0.1:5000)

## 💡 راهنمای استفاده

### ۱. صفحه اصلی (Dashboard)
در صفحه اصلی، آزمون‌ها به صورت خودکار به سه دسته **عمومی**، **دستورات لینوکس** و **شبکه** تقسیم شده‌اند. می‌توانید روی هر کارت کلیک کرده و آزمون را شروع کنید.

### ۲. حالت آزمون هوشمند (AI Adaptive Mode)
با کلیک روی دکمه **"شروع آزمون هوشمند تطبیقی"** در صفحه اصلی:
1. سیستم ۴ سوال اول را از سطوح ۱ تا ۴ به شما نمایش می‌دهد تا سطح شما را بسنجد.
2. یک تایمر برای هر سوال فعال می‌شود.
3. پس از سوال چهارم، اگر سریع و درست پاسخ دهید، سطح دشواری بالا می‌رود (🚀) و اگر اشتباه پاسخ دهید، سطح برای تثبیت یادگیری کاهش می‌یابد (📉).

### ۳. پنل ساخت آزمون (`/create`)
برای افزودن آزمون جدید، به آدرس `http://127.0.0.1:5000/create` بروید. سه روش دارید:
- **ورود دستی**: پر کردن فیلدها به صورت فرم (با پشتیبانی از فیلدهای مخصوص دستورات مثل `command` و `example`).
- **چسباندن هوشمند**: کپی کردن متن سوالات از PDF/Word و کلیک روی "چسباندن خودکار از کلیپ‌بورد" برای تبدیل فرمت.
- **تولید با AI**: استفاده از پرامپت از پیش تنظیم‌شده برای دریافت سوالات JSON استاندارد از مدل‌های زبانی بزرگ.

## ⚙️ فرمت فایل‌های JSON
فایل‌های آزمون در پوشه `data/` باید ساختار زیر را داشته باشند:

```json
{
  "title": "عنوان آزمون",
  "description": "توضیح کوتاه درباره آزمون",
  "type": "general", 
  "level": "1",
  "questions": [
    {
      "id": 1,
      "category": "مدیریت فایل",
      "level": 2,
      "text": "متن سوال <code>ls -l</code> چیست؟",
      "command": "ls -l",
      "example": "drwxr-xr-x 2 user user 4096",
      "options": ["گزینه ۱", "گزینه ۲", "گزینه ۳", "گزینه ۴"],
      "correct": 0,
      "explanation": "توضیح کامل چرا این گزینه صحیح است."
    }
  ]
}
```
> **نکته**: فیلد `type` اختیاری است. اگر حذف شود، سیستم به صورت هوشمند بر اساس نام فایل و محتوا آن را تشخیص می‌دهد.
