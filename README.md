# 🧠 سامانه جامع آزمون‌سازی آنلاین

یک پلتفرم مدرن و کامل برای **ساخت، مدیریت، اجرا و تحلیل آزمون‌های چهارگزینه‌ای** با قابلیت‌های هوشمند.

این سامانه برای آموزش، خودآزمایی، مرور دروس، آمادگی آزمون و هر حوزه‌ای که نیاز به سیستم آزمون آنلاین داشته باشد طراحی شده است.

---

## ✨ قابلیت‌های اصلی

### 🎯 حالت‌های مختلف آزمون

#### آزمون معمولی

اجرای آزمون با امکان:

* مرور سوالات
* دسته‌بندی سوالات
* جستجو
* ثبت پاسخ
* مشاهده توضیحات پاسخ‌ها
* علامت‌گذاری سوالات مهم

#### 🤖 آزمون هوشمند تطبیقی (AI Adaptive)

سطح سوالات به‌صورت پویا بر اساس عملکرد کاربر تغییر می‌کند.

سیستم موارد زیر را در نظر می‌گیرد:

* درست یا غلط بودن پاسخ
* سرعت پاسخگویی
* سطح فعلی سوال
* عملکرد سوالات قبلی

هدف این حالت، ارائه سوالاتی متناسب با سطح واقعی کاربر است.

#### ❌ مرور سوالات غلط

نمایش و تمرین مجدد سوالاتی که کاربر قبلاً به آن‌ها پاسخ اشتباه داده است.

#### 🔖 نشان‌گذاری سوالات

کاربر می‌تواند سوالات مهم را Bookmark کند تا بعداً به آن‌ها مراجعه کند.

#### ✏️ ویرایش و 🗑️ حذف سوال

پس از پاسخ دادن به سوال، امکان ویرایش یا حذف آن وجود دارد.

تغییرات مستقیماً در فایل JSON ذخیره می‌شوند و دائمی هستند.

# 📝 ساخت آزمون

سامانه سه روش برای ایجاد آزمون ارائه می‌دهد:

### 1. ورود دستی

ایجاد آزمون با فرم اختصاصی و وارد کردن اطلاعات:

* عنوان
* توضیحات

سیستم تلاش می‌کند ساختار متن را تشخیص داده و آن را به فرمت JSON استاندارد تبدیل کند.

* ChatGPT
* Claude
* Gemini

ارائه می‌کند تا بتوان سوالات استاندارد و قابل استفاده در سامانه تولید کرد.

این قابلیت محدود به یک موضوع خاص نیست و برای موضوعات مختلف قابل استفاده است.

# 🚀 نصب و راه‌اندازی

## پیش‌نیازها

* Python 3.8+
* pip
* Git

## 1. دریافت پروژه

```bash
git clone https://github.com/bigZeroR/quiz-server.git
cd quiz-server
```

## 2. ایجاد محیط مجازی

### Linux / macOS

```bash
python3 -m venv venv
source venv/bin/activate
```

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

## 3. نصب وابستگی‌ها

```bash
pip install -r requirements.txt
```

## 4. اجرای سرور

```bash
python server.py
```

## 5. ورود به سامانه

پس از اجرای سرور، مرورگر را باز کرده و وارد آدرس زیر شوید:

```text
http://127.0.0.1:5000
```

# 🤖 حالت AI Adaptive

با انتخاب گزینه **«شروع آزمون هوشمند تطبیقی»**:

### مرحله اول — کالیبراسیون

چهار سوال ابتدایی از سطوح مختلف انتخاب می‌شوند:

```text
Level 1
Level 2
Level 3
Level 4
```

### مرحله دوم — تحلیل عملکرد

برای هر پاسخ موارد زیر بررسی می‌شوند:

* صحت پاسخ
* زمان پاسخگویی
* سطح سوال

### مرحله سوم — تنظیم سطح

سیستم بر اساس عملکرد کاربر، سطح سوال بعدی را تغییر می‌دهد.

### مرحله چهارم — فیدبک

تغییر سطح با استفاده از:

* رنگ
* انیمیشن
* پیام وضعیت

به کاربر نمایش داده می‌شود.

سوالاتی که قبلاً پاسخ داده شده‌اند مجدداً در همان جلسه نمایش داده نمی‌شوند.

---

# 📈 الگوریتم تطبیقی

امتیاز عملکرد به شکل زیر محاسبه می‌شود:

| وضعیت                        | امتیاز |
| ---------------------------- | -----: |
| پاسخ صحیح و کمتر از ۱۰ ثانیه |   `+2` |
| پاسخ صحیح بین ۱۰ تا ۲۰ ثانیه |   `+1` |
| پاسخ صحیح بیشتر از ۲۰ ثانیه  |    `0` |
| پاسخ اشتباه                  |   `-1` |

### نتیجه

```text
+2 → افزایش سطح
+1 → حفظ / پیشروی کنترل‌شده
 0 → حفظ سطح
-1 → کاهش سطح
```

# 📦 فرمت JSON آزمون

هر آزمون در قالب JSON ذخیره می‌شود:

```json
{
  "title": "عنوان آزمون",
  "description": "توضیح کوتاه",
  "type": "general",
  "level": "1",
  "questions": [
    {
      "id": 1,
      "category": "دسته‌بندی",
      "level": 2,
      "text": "متن سوال با <code>کد</code>",
      "command": "ls -la",
      "example": "drwxr-xr-x 2 user user 4096",
      "options": [
        "گزینه ۱",
        "گزینه ۲",
        "گزینه ۳",
        "گزینه ۴"
      ],
      "correct": 0,
      "explanation": "توضیح پاسخ صحیح"
    }
  ]
}
```

---

# 🧩 فیلدهای JSON

| فیلد          | توضیح                          |
| ------------- | ------------------------------ |
| `title`       | عنوان آزمون                    |
| `description` | توضیح آزمون                    |
| `type`        | نوع آزمون                      |
| `level`       | سطح کلی آزمون                  |
| `questions`   | آرایه سوالات                   |
| `id`          | شناسه سوال                     |
| `category`    | دسته‌بندی سوال                 |
| `level`       | سطح سوال                       |
| `text`        | متن سوال                       |
| `command`     | دستور، مخصوص آزمون‌های Command |
| `example`     | مثال، مخصوص آزمون‌های Command  |
| `options`     | چهار گزینه                     |
| `correct`     | ایندکس گزینه صحیح              |
| `explanation` | توضیح پاسخ                     |

### مقادیر `type`

```text
general
command
network
```

در صورت نبودن `type`، سیستم می‌تواند نوع آزمون را به‌صورت خودکار تشخیص دهد.

### مقدار `correct`

ایندکس گزینه صحیح از `0` تا `3` است:

```text
0 → گزینه اول
1 → گزینه دوم
2 → گزینه سوم
3 → گزینه چهارم
```

# 🔍 تشخیص خودکار نوع آزمون

سیستم از یک الگوریتم تشخیص هیبریدی استفاده می‌کند.

اولویت تشخیص:

```text
1. فیلد type در JSON
        ↓
2. نام فایل
        ↓
3. عنوان آزمون
        ↓
4. محتوای سوالات
        ↓
5. general
```

### مثال

اگر فایل شامل `command` یا `network` در نام خود باشد، سیستم می‌تواند نوع آن را تشخیص دهد.

همچنین وجود فیلدهایی مانند:

```json
"command": "ls -la"
```

یا:

```json
"example": "..."
```

می‌تواند در تشخیص نوع آزمون مورد استفاده قرار گیرد.

# 🔌 API

| Method | Endpoint               | کاربرد            |
| ------ | ---------------------- | ----------------- |
| `GET`  | `/`                    | صفحه اصلی         |
