# سامانه جامع آزمون‌سازی آنلاین با قابلیت‌های هوشمند، طراحی مدرن و تجربه کاربری روان

یک پلتفرم کامل برای ایجاد، مدیریت و شرکت در آزمون‌های تستی چهارگزینه‌ای در هر موضوعی. مناسب برای آموزش، خودآزمایی، و آمادگی برای هر نوع آزمون.

## ویژگی‌ها

### حالت‌های آزمون
- آزمون معمولی: مرور سوالات با دسته‌بندی و جستجو
- آزمون هوشمند تطبیقی (AI Mode): تنظیم خودکار سطح دشواری بر اساس عملکرد و سرعت پاسخگویی شما
- مرور غلط‌ها: تمرکز روی سوالاتی که اشتباه پاسخ داده‌اید
- نشان‌گذاری (Bookmarks): علامت‌گذاری سوالات مهم برای مرور بعدی
- ویرایش و حذف سوالات: پس از پاسخ دادن، می‌توانید سوال را ویرایش یا حذف کنید (تغییرات دائمی در فایل JSON)

### ساخت آزمون
- ورود دستی: فرم فیلد به فیلد با اعتبارسنجی
- پیست هوشمند: تبدیل خودکار متن از کلیپ‌بورد به JSON
- تولید با AI: پرامپت مهندسی‌شده برای ChatGPT/Claude/Gemini (همه‌موضوعی)

### پنل کاربری
- نمایش آمار کلی (تعداد آزمون‌ها، دقت، بوک‌مارک‌ها)
- تحلیل نقاط ضعف و قوت
- خروجی‌گیری از داده‌ها (Backup)
- ریست سراسری داده‌ها

### رابط کاربری
- تم تاریک حرفه‌ای با انیمیشن‌های روان
- کاملاً ریسپانسیو (موبایل، تبلت، دسکتاپ)
- پشتیبانی کامل از زبان فارسی (فونت وزیرمتن)
- نمایش کدهای درون‌خطی با فونت مونو
- نوتیفیکیشن‌های Toast برای بازخورد فوری

## تکنولوژی‌ها

بخش Backend: Python, Flask
بخش Frontend: HTML5, CSS3 (Custom Properties), Vanilla JavaScript
ذخیره‌سازی: LocalStorage (سمت کلاینت) + فایل‌های JSON (سمت سرور)
فونت‌ها: Vazirmatn (فارسی), JetBrains Mono (کد)

## نصب و راه‌اندازی

پیش‌نیازها:
- Python 3.8 یا بالاتر
- pip

مراحل نصب:

1. کلون کردن پروژه
git clone https://github.com/bigZeroR/quiz-server.git
cd quiz-server

2. ایجاد محیط مجازی (توصیه می‌شود)
python3 -m venv venv
source venv/bin/activate  # Linux/Mac
# یا: venv\Scripts\activate  # Windows

3. نصب وابستگی‌ها
pip install -r requirements.txt

4. اجرای سرور
python server.py

5. باز کردن در مرورگر
http://127.0.0.1:5000

## راهنمای استفاده

### صفحه اصلی
در صفحه اصلی، آزمون‌ها بر اساس نوع (عمومی، دستورات، شبکه) دسته‌بندی می‌شوند. با این حال، سیستم برای هر موضوعی قابل استفاده است و شما می‌توانید آزمون‌های دلخواه خود را در هر زمینه‌ای ایجاد کنید.

### حالت AI Adaptive
با کلیک روی دکمه "شروع آزمون هوشمند تطبیقی":
- یک مودال زیبا برای انتخاب آزمون نمایش داده می‌شود
- ۴ سوال اول از سطوح ۱ تا ۴ نمایش داده می‌شوند
- تایمر برای هر سوال فعال می‌شود
- بر اساس درستی پاسخ و سرعت عمل، سطح بعدی تنظیم می‌شود
- سوالات پاسخ‌داده‌شده دیگر نمایش داده نمی‌شوند

### ویرایش و حذف سوالات (قابلیت جدید)
- پس از پاسخ دادن به هر سوال، دو دکمه ✏️ (ویرایش) و 🗑️ (حذف) در بالای سوال ظاهر می‌شوند
- با کلیک روی ✏️، یک مودال باز می‌شود که امکان تغییر متن، گزینه‌ها، پاسخ صحیح و توضیح را فراهم می‌کند
- با کلیک روی 🗑️، سوال برای همیشه از فایل JSON حذف می‌شود
- تغییرات به‌صورت دائمی ذخیره شده و برای همه کاربران اعمال می‌شود

### جستجوی جامع
- در صفحه اصلی، یک نوار جستجوی جامع وجود دارد
- می‌توانید در تمام سوالات تمام آزمون‌ها جستجو کنید
- نتایج با برجسته‌سازی عبارت نمایش داده می‌شوند

### ساخت آزمون (/create)
سه روش برای افزودن آزمون:
- ورود دستی: پر کردن فرم فیلد به فیلد
- پیست هوشمند: چسباندن متن از Word/PDF
- تولید با AI: استفاده از پرامپت آماده برای ChatGPT (همه‌موضوعی)

### پنل کاربری (/dashboard)
- مشاهده آمار کلی
- تحلیل پیشرفت در هر آزمون
- شناسایی نقاط ضعف
- خروجی‌گیری از داده‌ها

## فرمت فایل JSON

{
  "title": "عنوان آزمون",
  "description": "توضیح کوتاه",
  "type": "general",
  "level": "1",
  "questions": [
    {
      "id": 1,
      "category": "دسته‌بندی",
      "level": 2,
      "text": "متن سوال با <code>کد</code>",
      "command": "ls -la",
      "example": "drwxr-xr-x 2 user user 4096",
      "options": ["گزینه ۱", "گزینه ۲", "گزینه ۳", "گزینه ۴"],
      "correct": 0,
      "explanation": "توضیح پاسخ صحیح"
    }
  ]
}

فیلدها:
- type: general | command | network (اختیاری - تشخیص خودکار)
- command: فقط برای نوع command
- example: فقط برای نوع command
- correct: ایندکس گزینه صحیح (0-3)

## API Endpoints

متد GET مسیر / صفحه اصلی
متد GET مسیر /quiz/<name> صفحه آزمون
متد GET مسیر /create پنل ساخت آزمون
متد GET مسیر /dashboard پنل کاربری
متد POST مسیر /api/save_quiz ذخیره آزمون جدید
متد POST مسیر /api/edit_question ویرایش یک سوال
متد POST مسیر /api/delete_question حذف یک سوال
متد GET مسیر /api/reload بارگذاری مجدد کش
متد GET مسیر /api/search جستجوی جامع در تمام سوالات

## الگوریتم تشخیص نوع آزمون

سیستم به صورت هیبریدی نوع آزمون را تشخیص می‌دهد:
1. فیلد صریح type در JSON (اولویت اول)
2. نام فایل (اگر شامل command یا network باشد)
3. عنوان آزمون (جستجوی کلمات کلیدی)
4. محتوای سوالات (بررسی وجود فیلد command یا example)
5. پیش‌فرض: general

## حالت AI Adaptive

الگوریتم امتیازدهی:

عملکرد صحیح با زمان کمتر از ۱۰ ثانیه: +2 (افزایش سطح)
عملکرد صحیح با زمان ۱۰ تا ۲۰ ثانیه: +1 (حفظ سطح)
عملکرد صحیح با زمان بیشتر از ۲۰ ثانیه: 0 (حفظ سطح)
عملکرد غلط: -1 (کاهش سطح)

مراحل:
1. فاز کالیبراسیون: ۴ سوال اول از سطوح ۱ تا ۴
2. فاز تطبیقی: تنظیم سطح بر اساس عملکرد
3. فیدبک بصری: نمایش تغییر سطح با رنگ و انیمیشن

## ذخیره‌سازی داده‌ها

داده‌های کاربر در LocalStorage مرورگر ذخیره می‌شوند:
- lpic_<quiz_name>_answers: پاسخ‌های کاربر
- lpic_<quiz_name>_stats: آمار (صحیح/غلط)
- lpic_<quiz_name>_bookmarks: نشان‌گذاری‌ها

پاک‌سازی داده‌ها:
- دکمه "ریست کامل" در صفحه آزمون
- دکمه "پاک کردن تمام داده‌ها" در پنل کاربری
