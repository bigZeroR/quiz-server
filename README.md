# سامانه آزمون آنلاین برای آمادگی آزمون‌های LPIC-1 و Network+ با قابلیت‌های هوشمند، طراحی مدرن و تجربه کاربری روان.

## ✨ ویژگی‌ها

### 🎯 حالت‌های آزمون
- **آزمون معمولی**: مرور سوالات با دسته‌بندی و جستجو
- **آزمون هوشمند تطبیقی (AI Mode)**: تنظیم خودکار سطح دشواری بر اساس عملکرد و سرعت پاسخگویی شما
- **مرور غلط‌ها**: تمرکز روی سوالاتی که اشتباه پاسخ داده‌اید
- **نشان‌گذاری (Bookmarks)**: علامت‌گذاری سوالات مهم برای مرور بعدی

### 🛠️ ساخت آزمون
- **ورود دستی**: فرم فیلد به فیلد با اعتبارسنجی
- **پیست هوشمند**: تبدیل خودکار متن از کلیپ‌بورد به JSON
- **تولید با AI**: پرامپت مهندسی‌شده برای ChatGPT/Claude/Gemini

### 📊 پنل کاربری
- نمایش آمار کلی (تعداد آزمون‌ها، دقت، بوک‌مارک‌ها)
- تحلیل نقاط ضعف و قوت
- خروجی‌گیری از داده‌ها (Backup)
- ریست سراسری داده‌ها

### 🎨 رابط کاربری
- تم تاریک حرفه‌ای با انیمیشن‌های روان
- کاملاً ریسپانسیو (موبایل، تبلت، دسکتاپ)
- پشتیبانی کامل از زبان فارسی (فونت وزیرمتن)
- نمایش کدهای درون‌خطی با فونت مونو
- نوتیفیکیشن‌های Toast برای بازخورد فوری

## 🛠️ تکنولوژی‌ها

## 🚀 نصب و راه‌اندازی

### پیش‌نیازها
- Python 3.8 یا بالاتر
- pip

### مراحل نصب

```bash
# 1. کلون کردن پروژه
git clone https://github.com/bigZeroR/quiz-server.git
cd quiz-server

# 2. ایجاد محیط مجازی (توصیه می‌شود)
python3 -m venv venv
source venv/bin/activate  # Linux/Mac
# یا: venv\Scripts\activate  # Windows

# 3. نصب وابستگی‌ها
pip install -r requirements.txt

# 4. اجرای سرور
python server.py

# 5. باز کردن در مرورگر
# http://127.0.0.1:5000
```

## 🎮 راهنمای استفاده

### 1. صفحه اصلی
در صفحه اصلی، آزمون‌ها به سه دسته تقسیم می‌شوند:
- 📘 عمومی (General): سوالات مفهومی و تئوری
- 🐧 دستورات (Command): سوالات عملی با دستورات لینوکس
- 🌐 شبکه (Network): سوالات Network+

### 2. حالت AI Adaptive
با کلیک روی دکمه "شروع آزمون هوشمند تطبیقی":
- ۴ سوال اول از سطوح ۱ تا ۴ نمایش داده می‌شوند
- تایمر برای هر سوال فعال می‌شود
- بر اساس درستی پاسخ و سرعت عمل، سطح بعدی تنظیم می‌شود

### 3. ساخت آزمون (/create)
سه روش برای افزودن آزمون:
- ورود دستی: پر کردن فرم فیلد به فیلد
- پیست هوشمند: چسباندن متن از Word/PDF
- تولید با AI: استفاده از پرامپت آماده برای ChatGPT

### 4. پنل کاربری (/dashboard)
- مشاهده آمار کلی
- تحلیل پیشرفت در هر آزمون
- شناسایی نقاط ضعف
- خروجی‌گیری از داده‌ها

## 📝 فرمت فایل JSON

```json
{
  "title": "عنوان آزمون",
  "description": "توضیح کوتاه",
  "type": "general",
  "level": "1",
  "questions": [
    {
      "id": 1,
      "category": "دسته‌بندی",
      "level": 2,
      "text": "متن سوال با <code>کد</code>",
      "command": "ls -la",
      "example": "drwxr-xr-x 2 user user 4096",
      "options": ["گزینه ۱", "گزینه ۲", "گزینه ۳", "گزینه ۴"],
      "correct": 0,
      "explanation": "توضیح پاسخ صحیح"
    }
  ]
}
```

### فیلدها
- **type**: general | command | network (اختیاری - تشخیص خودکار)
- **command**: فقط برای نوع command
- **example**: فقط برای نوع command
- **correct**: ایندکس گزینه صحیح (0-3)

## 🔌 API Endpoints

| متد | مسیر | توضیح |
|-----|------|-------|
| GET | / | صفحه اصلی |
| GET | /quiz/<name> | صفحه آزمون |
| GET | /create | پنل ساخت آزمون |
| GET | /dashboard | پنل کاربری |
| POST | /api/save_quiz | ذخیره آزمون جدید |
| GET | /api/reload | بارگذاری مجدد کش |
| GET | /api/quiz/<name> | دریافت JSON آزمون |

## 🧠 الگوریتم تشخیص نوع آزمون

سیستم به صورت هیبریدی نوع آزمون را تشخیص می‌دهد:
1. فیلد صریح type در JSON (اولویت اول)
2. نام فایل (اگر شامل command یا network باشد)
3. عنوان آزمون (جستجوی کلمات کلیدی)
4. محتوای سوالات (بررسی وجود فیلد command یا example)
5. پیش‌فرض: general

## 🎯 حالت AI Adaptive

### الگوریتم امتیازدهی

| عملکرد | زمان | تغییر سطح |
|--------|------|-----------|
| ✅ صحیح | < 10 ثانیه | +2 (افزایش سطح) |
| ✅ صحیح | 10-20 ثانیه | +1 (حفظ سطح) |
| ✅ صحیح | > 20 ثانیه | 0 (حفظ سطح) |
| ❌ غلط | - | -1 (کاهش سطح) |

### مراحل
1. فاز کالیبراسیون: ۴ سوال اول از سطوح ۱ تا ۴
2. فاز تطبیقی: تنظیم سطح بر اساس عملکرد
3. فیدبک بصری: نمایش تغییر سطح با رنگ و انیمیشن

## 💾 ذخیره‌سازی داده‌ها

داده‌های کاربر در LocalStorage مرورگر ذخیره می‌شوند:
- `lpic_<quiz_name>_answers`: پاسخ‌های کاربر
- `lpic_<quiz_name>_stats`: آمار (صحیح/غلط)
- `lpic_<quiz_name>_bookmarks`: نشان‌گذاری‌ها

### پاک‌سازی داده‌ها
- دکمه "ریست کامل" در صفحه آزمون
- دکمه "پاک کردن تمام داده‌ها" در پنل کاربری
